# CareerMatch AI

Nền tảng AI tuyển dụng số 1 cho sinh viên Việt Nam - kết nối sinh viên với cơ hội thực tập và việc làm phù hợp.

## Tech Stack
- React 19 + TypeScript
- Vite
- React Router DOM
- Tailwind CSS

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Features
- Tìm kiếm việc làm với AI matching
- Phân tích CV bằng AI
- Theo dõi ứng tuyển
- Hồ sơ sinh viên
- Dashboard nhà tuyển dụng
- Đăng tin tuyển dụng
- Quản lý ứng viên
